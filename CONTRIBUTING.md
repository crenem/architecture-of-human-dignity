# Contributing

Welcome. The project is explicitly inspired by Catholic social teaching, but **you need not be Catholic, religious, or in agreement with the project's proposals** to contribute. Rigorous disagreement is a contribution when it is evidence-based and respectful.

### Good contributions
- Verify paragraph-level references in primary sources.
- Correct mistakes of attribution, chronology and doctrinal interpretation.
- Contribute careful accounts of how AI affects workers, communities and persons receiving essential services, without disclosing identifiable personal information.
- Design adversarial test cases exposing both domination and paternalism.
- Test authorial economic mechanisms under realistic constraints and alternative models.
- Propose accessible documentation, transparent governance and practical corrective action.

### Requirements for a contribution
Describe **the claim**, **source or evidence**, **interpretive status** (doctrine / author proposal / empirical result / project hypothesis / license term), **affected persons**, **best objection**, and **how the change could be tested**.

Do not commit private manuscripts, confidential service records, copyrighted source text, photos or identifying case data without necessary authorization.

### Rights and licensing
This repository currently contains [[LICENSE|an experimental HDPL draft]]. **It is not a standard OSI open-source license.** Before contributing substantial copyrightable material, review current repository terms and raise questions about ownership, inbound licensing, and redistribution rights. No blanket assignment or contributor agreement is represented as adopted. A contributor should not assume a proposed license condition is already legally validated.

### Process
Open a narrowly scoped issue; propose source or test evidence; submit a pull request; preserve substantive disagreements in the review; avoid changing legal language in a general editorial commit. Maintainers must articulate reasons for accepting or rejecting rights-critical changes.

### Review values
Listen seriously; disagree without humiliation; separate facts from judgments; protect minority and dissenting voices; correct mistakes publicly when appropriate; prioritize real remedies over symbolic statements.

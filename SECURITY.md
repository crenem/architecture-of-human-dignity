# Security and Responsible Disclosure
## Protect people before publishing defects

This is currently a documentation and research repository, **not a deployed service or verified secure software product**.

Do not post real access tokens, private client records, health information, security keys, confidential credentials or identifiable incident data in public issues or pull requests. Use the platform's private reporting mechanisms where available; otherwise seek an agreed private channel with the repository owner before transmitting details.

Security reports should include affected component, reproducible steps using non-sensitive data, plausible impact and recommended containment. Do not test against third-party systems or expose actual users without permission.

If a security risk could affect real persons, take proportionate protective action first and coordinate publication of details after remediation. No response-time promise or bounty program is currently established.
